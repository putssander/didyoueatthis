What should the model try?

Continuation checks exact wording. Name cloze asks for one hidden name; correct guesses can also come from context. English text works best.

Adjust test size and scoring

A three-passage test is exploratory. Use at least five usable passages per text for a verdict; more passages and matched controls make comparisons more useful. Multiple prefix lengths share one hidden ending and count as one passage.

Understand the evidence

A useful experiment. An honest limit.

Exact recall can be evidence consistent with exposure. It cannot identify a training dataset, and a miss cannot show that your text was never used.

Before you read too much into a result.

What does a match actually mean?

For continuation, the first 20 normalised words must match by default: case and much punctuation are ignored. For name cloze, the reply must be the missing name, allowing surrounding punctuation. A hit could reflect memorisation, predictable text, or information available in the chat. Inspect the actual answers and compare with matched control text. The page’s categories are exploratory heuristics, not calibrated probabilities of training membership.

What if the model refuses or says “unknown”?

A refusal, empty reply or API error cannot establish absence. Try the public-domain example to check that the model can answer this kind of question. Name cloze may elicit an answer when continuation does not, but a correct name can be inferred from context.

What makes a good control?

Use text with similar length, subject, era and predictability that you have good reason to believe was unavailable to the model. A newly created Wikipedia article can reuse older writing, and encyclopaedia prose is a poor match for a novel. The quick book example starts without a control; add a suitable one before drawing conclusions.

Where do my documents and keys go?

Passage selection and scoring happen in this page. There is no project backend or analytics. In copy-paste mode, your chat provider receives the prompts you paste. In API mode, selected passages go directly to the selected providers. Wikipedia is contacted only when you click its button. Documents and answers are not saved across reloads; download a report to keep them. Remembered keys are stored on this device until you click Forget keys.

Is the August 2026 reasoning-trace leak the same thing?

No. Stealing Reasoning Traces from Proprietary LLM APIs concerns disclosure of reasoning traces and context data. That does not establish whether a document appeared in pretraining. This tool tests visible answers; it does not extract hidden reasoning.
